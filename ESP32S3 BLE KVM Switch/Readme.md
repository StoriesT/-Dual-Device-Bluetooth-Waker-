# 双设备蓝牙唤醒器 (Dual-Device Bluetooth Waker)

ESP32-S3 模拟一个**蓝牙键盘（BLE HID）**，在 Windows 和 Mac 两台电脑之间切换，并支持**唤醒**和**睡眠**。可通过**物理按键**、**小爱同学（米家/巴法云）**、**手机网页**三种方式控制。

## 解决的痛点

**多台电脑 + 一台带 KVM/hub 的显示器**是很多人的桌面配置，但切换电脑很麻烦：要么按显示器上的 OSD 按钮切输入源，要么手动拔插。

与其来回切输入源，不如直接把要用的电脑「唤醒」——电脑睡眠时蓝牙仍保持监听，一旦被唤醒，显示器检测到信号就会自动切到它，**键盘、鼠标、手柄全都跟着你唤醒的那台电脑走**，省得切来切去。

**笔记本用户尤其受益**：本子合盖塞在支架里，想唤醒得先开盖按电源键。有了它，直接蓝牙唤醒合盖的笔记本，不用碰本子。

一句话概括：**一个放在桌面上的小盒子，按键 / 语音 / 手机点一下，就能决定「现在唤醒哪台电脑」，显示器和外设自动跟着切换。**

## 功能

- **BLE HID 键盘**：2 个槽位（`Waker-Win` / `Waker-Mac`），各自独立 MAC 与绑定，切换后无需重新配对
- **唤醒**：发送 5 次鼠标左键点击
- **睡眠**：
  - Windows → System Sleep 键（0x82）
  - Mac → `Control+Command+Q` 锁屏 + `Esc`
- **三种控制方式**：
  - 物理按键：短按=唤醒，**长按 3 秒=配对**
  - 小爱同学 / 米家：通过巴法云 MQTT（开=唤醒、关=睡眠）
  - 手机网页：唤醒 / 睡眠 / 配对 + Wi-Fi 配网
- **Wi-Fi**：AP+STA 混合，mDNS（`waker.local`）
- **蓝牙广播**：默认定向广播自动回连（扫描里不可见）；只有长按 3 秒 / 网页配对才普通广播（可被发现）

## 硬件

| 部件 | 连接 |
|---|---|
| 按键 1（Windows） | GPIO4 ↔ GND（内部上拉，低电平触发） |
| 按键 2（Mac） | GPIO5 ↔ GND |
| 反馈 LED | GPIO2（设为 -1 关闭） |

## 构建与烧录

用 PlatformIO：

```bash
pio run            # 编译
pio run -t upload  # 烧录
```

串口监视器波特率 115200。

## 配对与使用

1. 首次开机设备**静默**（不广播）。**长按按键 3 秒**（或网页「配对」）进入配对广播。
2. 在电脑蓝牙设置里配对 `Waker-Win`（Windows）/ `Waker-Mac`（Mac）。
3. 短按按键切换到对应电脑并唤醒；网页 / 小爱也能唤醒、睡眠。

> **睡眠唤醒需在主机开启「允许此设备唤醒计算机」：**
> - Windows：设备管理器 → 蓝牙 → 对应 HID 设备 → 电源管理 → 勾选「允许此设备唤醒计算机」
> - macOS：系统设置 → 蓝牙 → 高级 → 勾选「允许蓝牙设备唤醒这台电脑」

## 小爱同学 / 米家（巴法云）

1. 注册 [巴法云](https://cloud.bemfa.com)，创建两个**开关类型**设备。
2. 把 UID（私钥）和设备 topic 填入 `src/Config.h`（`BEMFA_UID`、`BEMFA_TOPIC_WINDOWS`、`BEMFA_TOPIC_MAC`）。
3. 米家 App → 添加设备 → **其他平台设备 → 巴法云** → 登录绑定。
4. 语音「**打开唤醒Windows / 打开唤醒Mac**」触发唤醒；关闭开关触发睡眠。

## 网页

- STA 模式：`http://waker.local`（或查串口打印的 IP）
- AP 模式：手机连 `Waker-Config` 热点（密码 `12345678`），开 `http://192.168.4.1`

网页提供：**唤醒 / 睡眠 / 配对** 按钮 + Wi-Fi 配网表单。

## 配置

所有引脚、设备名、Wi-Fi、巴法云、唤醒/睡眠参数都集中在 [`src/Config.h`](src/Config.h)。

## 架构

```
main.cpp ──► Controller（状态机 + 命令路由，唯一决策者）
              ├─ 输入：ButtonManager / CloudManager(巴法云) / WebManager
              └─ 输出：BLEManager（BLE HID）/ WiFiManager / LED
```

三路输入统一汇入 `Controller::requestWake()` / `requestSleep()` / `requestPair()`。切换槽位通过「保存绑定 + 重启重连」实现，`pendingAction` 存 NVS，保证重连成功后执行对应动作。
